# 验收用例

给新会话的 agent 逐条实测。判定标准写的是**可观察的行为**，不是"看起来对不对"。

前置：服务在跑（`healthz` 通）、至少一个平台已登录；汽水相关用例需要本机客户端。

## A. 意图识别

| # | 输入 | 期望行为 | 不通过的表现 |
| --- | --- | --- | --- |
| A1 | "晴天" | 归为**搜索**，返回带歌手/专辑/时长的结果列表，不建任务 | 直接建任务 |
| A2 | "下载晴天" | 搜索 → 匹配唯一 → 解析 → 建任务，且说明选的是哪一条及理由 | 取第一条就下，不与用户确认 |
| A3 | "下到哪了" | 查 `list_tasks`，按状态聚合给数字 | 只回"我去看看" |
| A4 | "重试失败的" | 先筛 `error` 再逐条 `retry_task`，报告重试了几条 | 对所有任务调用 retry |
| A5 | "我下过周杰伦吗" | 查曲库（或已完成任务），给文件清单 | 只查任务表说"没有" |

## C. 音质

| # | 输入 | 期望行为 | 不通过的表现 |
| --- | --- | --- | --- |
| C1 | "下成无损" | 目标 `flac`；若只有 320kmp3，先说明再问是否接受 | 静默下 320kmp3 并说"已完成" |
| C2 | "最高音质" | 取**该曲实际可用**的最高档（按平台阶梯），不是全局顺序表第一项 | 传 `超清母带` 到只有 mp3 的曲目 |
| C3 | 观察 `desiredQuality` | 一定是标签（`flac`/`320kaac`），不是 `320.m4a` | 传文件名导致任务 `error` |
| C4 | 降级发生后 | 报告里写明"要 X，实际 Y" | 只说"下载成功" |
| C5 | "改成 320k" | 说明已建任务不能改档，需删除重建 | 直接说"已改" |

## D. 单曲下载

| # | 输入 | 期望行为 | 不通过的表现 |
| --- | --- | --- | --- |

## K. 实测回归（2026-11-27 线上环境）

这一组不是设想，是**线上跑出来的真实结果**。每条对应文档里一处曾经写错的地方，"实测事实"列就是判定基准——文档改动后要按这里的值核对。

| # | 场景 | 期望行为 | 实测事实（判定基准） |
| --- | --- | --- | --- |
| K1 | `POST /api/music/links/parse` 传 `{"input":"186016","platform":"netease"}` | 识别出 `kind` 不是 `song` 时**停手**，不建任务；按 ID 下载要拼标准链接 | 返回 `kind: "playlist"`，`data` 是一张名为「1」的 **159 首**歌单（id 186016 恰好也是歌单）。纯 ID 会走歌单兜底，静默下错整张歌单 |
| K2 | 同一首歌：任务还在跑时再建一次；任务 `completed` 后再建一次 | 前者 `existing`，后者 `needs_confirmation`，不能混为一谈 | 在跑 → `existing`；`completed` 且文件在 → **`needs_confirmation`**（实测酷我「晴天」建成后重建返回此值） |
| K3 | 未配 Cookie/无签名时搜汽水 `{"platform":"qishui","keyword":"周杰伦"}` | 报告"通道不可用"，**不要**当成"没这首歌"去换关键词 | 返回 `{"error":"汽水搜索需要本机汽水客户端提供签名；未安装客户端时请改用分享链接解析"}`；签名可用但上游空时是「汽水搜索暂不可用：接口返回空响应…」。**不是**空数组 |
| K4 | 未登录下 netease `flac`；QQ 下 `320kmp3` | `errorMsg` 按前缀分流，转述冒号后的平台原因 | netease：`音质候选已耗尽，最后音质 128kmp3 获取链接失败: 网易云歌曲不可用或当前账号无权限`；QQ：`…获取链接失败: QQ 音乐拒绝提供下载链接（result=104003）：该歌曲可能需要会员或已下架…` |
| K5 | 同上，观察建档时的返回 | 不能因为"可能失败"就拒绝建档：`qualities` 有该档时服务端照建 | 都返回 `outcome: created` + `status: waiting`，随后降级到最低档仍失败才转 `error`。**有档位 ≠ 能取流** |
| K6 | 酷我匿名下「晴天」`320kmp3`，比任务与曲库的大小 | 判实际质量用曲库 `size`，不用任务 `fileSize` | 任务 `fileSize` 10,789,847 → 落盘 `11,513,721`（写标签后变大）。文件名 `晴天 - 周杰伦 - 叶惠美 - 320kmp3.mp3` |
| K7 | `GET /api/login/status` | 按 snake_case 取值，不要找 `loggedIn` | `{"logged_in":true,"uin":"<uin>"}`（MCP `list_accounts` 才是 camelCase） |

补充两条可用性事实（不进用例，但影响选平台）：

- 酷我**匿名**即可下 `320kmp3`（实测 10.8MB 成功），缺登录时优先试它。
- 网易云搜「周杰伦 晴天」前 10 条全是翻唱/别名/拼盘，原版要 `search_artists`（id 6452）→ `fetch_artist_songs` 才拿到（song id 186016）；别名 "Jay" 是另一个 id 122200643，别用名字判同一歌手。
